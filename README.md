# 📌 О проекте

**FRK Mobile App** — проект по созданию мобильного приложения для внутреннего использования компании FRK Corp. Разработка разбита на две части: серверную (FastAPI) и мобильную (Kotlin). В данный момент описывается серверная часть.

Сервер обеспечивает:

* регистрацию и авторизацию пользователей
* хранение профилей и статистики пользователей
* обмен сообщениями между пользователями
* загрузку и хранение медиафайлов (аватары, документы)
* выдачу данных мобильному приложению через REST API

---

# ⚙️ Основные возможности

## Авторизация и регистрация

Сервер поддерживает регистрацию новых пользователей с проверкой уникальности email и username. Пароли хэшируются с использованием алгоритма **bcrypt** перед сохранением в базу данных.

---

## Управление профилем

Через API доступны эндпоинты для обновления данных пользователя:

* основные данные (email, username, имя, фамилия)
* тип пользователя (`usertype`)
* аватар

---

## Система сообщений

Сервер хранит историю переписки между пользователями и предоставляет эндпоинты для:

* отправки сообщений
* получения истории переписки между двумя пользователями
* получения списка всех диалогов текущего пользователя

---

## Загрузка файлов

Поддерживается загрузка файлов (аватары, документы и др.) на сервер. Каждому файлу присваивается уникальное имя через `uuid`, метаданные сохраняются в БД, а сам файл отдаётся по статическому URL.

# 🌐 REST API — Эндпоинты

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/test` | Проверка работоспособности сервера |
| `POST` | `/register` | Регистрация нового пользователя |
| `POST` | `/login` | Авторизация пользователя |
| `POST` | `/updateUserData` | Обновление данных профиля |
| `POST` | `/updateUserType` | Изменение типа пользователя |
| `POST` | `/updateAvatar` | Обновление аватара |
| `POST` | `/sendMessage` | Отправка сообщения |
| `GET` | `/getHistory` | История переписки между двумя пользователями |
| `GET` | `/getMessages` | Список всех диалогов текущего пользователя |
| `POST` | `/uploadFile` | Загрузка медиафайла на сервер |
| `GET` | `/getFile/{filename}` | Получение метаданных файла |

# 🗄️ Модели базы данных

### `users` — пользователи

| Поле | Тип | Описание |
|---|---|---|
| `id` | Integer | Первичный ключ |
| `email` | String | Уникальный email |
| `username` | String | Уникальный никнейм |
| `hashed_password` | String | Хэшированный пароль (bcrypt) |
| `usertype` | String | Тип пользователя |
| `userInfoName` | String | Имя |
| `userInfoSurname` | String | Фамилия |
| `userInfoAvatar` | String | URL аватара |
| `userStatProjects` | Integer | Количество проектов |
| `userStatTasks` | Integer | Количество задач |
| `userStatOntime` | Double | Процент выполнения в срок |
| `userCurrentEarnings` | Integer | Текущий заработок |
| `userAllTimeEarnings` | Integer | Заработок за всё время |

### `messages` — сообщения

| Поле | Тип | Описание |
|---|---|---|
| `id` | Integer | Первичный ключ |
| `textMessage` | String | Текст сообщения |
| `fromWho` | String | Отправитель |
| `toWho` | String | Получатель |
| `timeMessage` | String | Время отправки |

### `media_files` — медиафайлы

| Поле | Тип | Описание |
|---|---|---|
| `id` | Integer | Первичный ключ |
| `filename` | String | Уникальное имя файла |
| `owner` | String | Владелец файла |
| `file_type` | String | Тип файла (avatar, document и др.) |
| `url` | String | Публичный URL файла |
| `uploaded_at` | String | Дата и время загрузки |
